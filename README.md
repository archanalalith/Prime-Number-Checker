# 🔢 Prime Number Checker – Python Mini Project  

This mini project demonstrates how to check whether a number is **prime or not** using **two different approaches** in Python.  
It is part of my learning journey in the **Django and Python Developer Track** at **Entri Elevate**.  

---

## 🚀 Project Overview  
Prime numbers are a fundamental concept in programming and mathematics.  
This project helps strengthen my understanding of **functions, loops, and condition handling** by exploring two methods to check prime numbers:  

### 🧠 Methods Implemented  
1. **Mathematical Method** – Uses square root optimization to check divisibility.  
2. **Logical Method** – Iterative approach using loops and conditional statements.  

---

## 🧠 Concepts Practiced  
- Function definitions and calls  
- Conditional statements (`if`, `else`, `return`)  
- Loops and range iteration  
- Mathematical logic and performance optimization  

---

## 💻 Example Output  
Enter a number: 17
Prime check using Method 1: 17 is a Prime number.
Prime check using Method 2: 17 is a Prime number.
